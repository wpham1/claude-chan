Weeb-ify your [Claude Code](https://docs.anthropic.com/en/docs/claude-code) terminal with anime-themed spinner verbs, otaku tips, and kaomoji status line.

```
  (*^_^*) claude-chan setup wizard
  ─────────────────────────────────
  Choose which features to install.
  Press Enter to accept the default [Y/n].

  \(^o^)/ Anime spinner verbs? [Y/n]
  (*^_^*) Otaku tips? [Y/n]
  (o_o)   Kaomoji status line? [Y/n]
```

## What it does

claude-chan customises three cosmetic settings in Claude Code. Nothing functional is touched — your permissions, hooks, plugins, and model settings stay exactly as they are.

| Feature | What changes | Default |
|---------|-------------|:-------:|
| **Spinner verbs** | The action text while Claude thinks (e.g. *"Gathering chakra for 12s"*) | On |
| **Tips** | The rotating tips below the spinner (e.g. *"(^_~) Just according to keikaku."*) | On |
| **Status line** | Kaomoji face that reacts to your context usage: `(^_^)` → `(o_o)` → `(>_<)` → `(x_x)` | Off |

## Install

```bash
npx claude-chan
```

That's it. The interactive wizard walks you through which features to enable.

### Other options

```bash
npx claude-chan --all        # Install everything, no questions
npx claude-chan --theme      # Change color theme
npx claude-chan --preview    # See what would change without applying
npx claude-chan --help       # Show usage
```

## Uninstall

```bash
npx claude-chan --uninstall
```

Your original settings are restored from a backup created during install. Clean in, clean out.

## Color themes

The wizard lets you pick a color theme during setup. You can also change it anytime:

```bash
npx claude-chan --theme          # Interactive picker
npx claude-chan --theme miku     # Set directly by name
```

| Theme | Vibe |
|-------|------|
| **Miku** | Cyan & teal — Hatsune Miku vibes (default) |
| **Sakura** | Pink & soft magenta — cherry blossom energy |
| **Naruto** | Orange & yellow — believe it! |
| **Eva** | Purple & green — Evangelion palette |
| **Demon Slayer** | Red & dark — breath of the flame |
| **Jujutsu Kaisen** | Blue & purple — cursed energy |
| **None** | No colors — plain terminal output |

Colors apply to the claude-chan CLI output (banner, kaomoji, messages). Your color preference is stored in `~/.claude/.claude-chan-config.json`.

### Create your own theme

```bash
npx claude-chan --theme create
```

The wizard walks you through picking a name, description, and colors for each role (primary, accent, success, highlight).

Available colors: `black`, `red`, `green`, `yellow`, `blue`, `magenta`, `cyan`, `white`, and bright variants (`bright-red`, `bright-cyan`, etc).

You can also add themes directly in `~/.claude/.claude-chan-config.json`:

```json
{
  "theme": "my-theme",
  "customThemes": {
    "my-theme": {
      "name": "My Theme",
      "description": "My custom color scheme",
      "primary": "cyan",
      "accent": "magenta",
      "success": "green",
      "highlight": "bright-cyan"
    }
  }
}
```

Custom themes show up alongside the built-in ones in the theme picker.

## Customise it yourself

claude-chan writes to `~/.claude/settings.json`. You can edit these values directly to add your own verbs, tips, or tweak the ones installed.

### Add your own spinner verbs

Open `~/.claude/settings.json` and find the `spinnerVerbs` key:

```json
{
  "spinnerVerbs": {
    "mode": "replace",
    "verbs": [
      "Activating bankai",
      "Going plus ultra",
      "Your custom verb here"
    ]
  }
}
```

- `"mode": "replace"` — uses **only** your verbs
- `"mode": "append"` — adds your verbs **alongside** the Claude defaults

### Add your own tips

Find the `spinnerTipsOverride` key:

```json
{
  "spinnerTipsOverride": {
    "excludeDefault": true,
    "tips": [
      "(^_^) Your custom tip here",
      "(o_o) Another tip"
    ]
  }
}
```

- `"excludeDefault": true` — shows **only** your tips
- `"excludeDefault": false` — merges yours with the Claude defaults

### Tweak the status line

The status line runs a shell script at `~/.claude/weeb-statusline.sh`. Edit it to change the kaomoji or what info is displayed. The script receives JSON on stdin with context window, model, and cost data.

Current faces by context usage:

| Context used | Face |
|:---:|:---:|
| < 25% | `(^_^)` |
| 25-50% | `(o_o)` |
| 50-75% | `(>_<)` |
| > 75% | `(x_x)` |

## How it works

1. Reads your existing `~/.claude/settings.json`
2. Backs up current spinner/tips/statusline settings to `~/.claude/.weeb-backup.json`
3. Writes the theme values (only the 3 cosmetic keys)
4. On uninstall, restores from the backup

No dependencies. No build step. Just Node.js.
